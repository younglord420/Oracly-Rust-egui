egui-charts in a desktop webview

This page is embedded offline by examples/desktop_webview.rs with wry. No network is required for the smoke path.

What this shows

A native desktop shell can host the same WASM chart UI you ship for the browser (Trunk builds of examples/demo or examples/bare_chart.rs). Load the built assets from disk or a custom protocol; keep market data and storage in the host and talk to the page over IPC if needed.

Local HTML loaded

Embed the WASM / demo chart

  1. Build the web target, for example cd examples/demo && trunk build --release.
  2. Point the webview at the produced dist/ (file URL, asset protocol, or your app’s bundler such as Tauri).
  3. Prefer a custom protocol over file:// when you need fetch/WASM workers or stricter origin rules.
cargo run --example desktop_webview --features desktop-webview

Prefer a native egui window?

For charts drawn with egui directly (no webview), run the eframe examples such as basic_chart or live_feed, or assemble UI with the terminal package.
